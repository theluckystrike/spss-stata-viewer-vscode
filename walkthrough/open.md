## Open a data file

SPSS & Stata Viewer opens these files in VS Code:

- SPSS `.sav` (uncompressed or compressed) and `.zsav`
- Stata `.dta`, releases 113 to 119 (Stata 8 to 18), including long strings (strL)
- SAS transport `.xpt` (version 5, the FDA submission format)

The grid reads rows in pages, so a file with millions of rows opens fast. Click a column header to sort, use the filter box to find rows, and copy cells with Ctrl+C or Cmd+C.

The viewer is read-only and never changes your file.
