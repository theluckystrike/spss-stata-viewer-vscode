## 0.1.0

- First release: SPSS (.sav, .zsav), Stata (.dta releases 113 to 119) and SAS transport (.xpt version 5) viewer.
- Data grid with paged reading for millions of rows, sort, filter, value labels or codes, missing values and dates.
- Variables tab, Info tab, and a summary with frequencies for each variable.
- Copy cells and rows as tab-separated text.
- Zovo Pro tools with 3 free tries each: export to CSV, Excel or JSON; codebook as Markdown, HTML or CSV; crosstab with a chi-square test.
- Footer links (Rate, More free viewers, Zovo Pro, PayPal, Hide), a Support Zovo section in this README and a last walkthrough step with related free Zovo extensions.
